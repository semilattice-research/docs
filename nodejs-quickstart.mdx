## Get your API key

First, [sign up](https://semilattice.ai/sign-up) for a Semilattice account and create an API key from your dashboard.

## Install

Install the Semilattice Node.js SDK:

```bash
npm install semilattice
```

## Initialize the client

```javascript
const { Semilattice } = require('semilattice');

const semilattice = new Semilattice({
  apiKey: process.env['SEMILATTICE_API_KEY'], // This is the default and can be omitted
});
```

## Choose a Population Model

Navigate to the [Populations page](https://semilattice.ai/populations) on your dashboard and select a population model to use. Copy the UUID from the address bar after `/populations/...` (we'll improve this experience in the future).

## Simulate an answer

```javascript
const result = await semilattice.answers.simulate({
    population_id: "your-population-uuid-here",
    answers: {
        question: "Rain or wind, what's worse?",
        question_options: { question_type: "single-choice" },
        answer_options: ["Rain", "Wind"]
    }
});
```

## Poll for results

The simulation will progress through these statuses: `Queued` → `Running` → `Predicted` (or potentially `Failed`). Predictions typically take less than a minute.

Poll for the result using the answer ID:

```javascript
const answerId = result.data[0].id;

const pollForResult = async () => {
    while (true) {
        const answer = await semilattice.answers.get(answerId);
        
        if (answer.data.status === 'Predicted') {
            console.log("Simulation complete!");
            console.log(`Results: ${JSON.stringify(answer.data.simulated_answer_percentages)}`);
            return answer.data;
        } else if (answer.data.status === 'Failed') {
            console.log("Simulation failed");
            throw new Error("Simulation failed");
        }
        
        console.log(`Status: ${answer.data.status}`);
        await new Promise(resolve => setTimeout(resolve, 5000)); // Wait 5 seconds
    }
};

const finalResult = await pollForResult();
```
