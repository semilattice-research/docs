Populations are the core of Semilattice's prediction engine. When you make API calls to simulate answers, you're selecting a specific population model that represents the group of people you want to predict.

## What is a Population?

A Population is a trained model that represents a specific group of people. When you call the API with a `population_id`, you're telling Semilattice which group to simulate. Each population has unique characteristics that affect prediction accuracy and scope.

### Target Population

Each population targets a specific demographic or psychographic group. For example:
- `dev-population-uuid` might target software developers
- `marketing-exec-uuid` might target marketing executives
- `us-adults-uuid` might target general US adults

When choosing a `population_id` for your API calls, select the one that best matches your target audience.

Populations range from broad demographic groups to highly specific niches. The more specific the population, the more accurate predictions will be for that specific group, but the narrower the scope of applicable questions.

### Training Data
Populations are trained on real survey data from their target demographic. This training data determines:
- **Prediction accuracy**: How well the model predicts for similar questions
- **Subject expertise**: What topics the population can predict accurately
- **Response patterns**: How the group typically answers questions

### Accuracy Metrics

Every population includes accuracy metrics that help you understand prediction reliability:

<Frame caption="Accuracy metrics help assess prediction confidence">
  <img src="/images/populations/introduction/evaluation_metrics.png" />
</Frame>

These metrics appear in API responses and help you:
- Choose the right population for your use case
- Set appropriate confidence levels for your predictions
- Understand the reliability of specific results

### Simulation Engine

Each population uses a specific version of Semilattice's simulation engine. This ensures:
- **Consistency**: All predictions use the same model version
- **Accuracy**: Evaluation metrics reflect real prediction performance
- **Reliability**: Results are reproducible

<Frame caption="Populations use consistent simulation engines">
  <img src="/images/populations/introduction/simulation_engine.png" />
</Frame>

The `simulation_engine` field in API responses tells you which version was used.

### Public vs. Private Populations

When making API calls, you can access:
- **Public populations**: Available to all users with valid API keys
- **Private populations**: Only accessible to the owner's API key

## Finding Population IDs

To use a population in your API calls, you need its UUID. You can find population IDs by:

1. **Dashboard**: Browse populations at [semilattice.ai/populations](https://semilattice.ai/populations) and copy the UUID from the URL
2. **API**: Use the populations endpoint to list available populations programmatically

```python
# Example: List available populations
populations = semilattice.populations.list()
for pop in populations['data']:
    print(f"{pop['name']}: {pop['id']}")
```
