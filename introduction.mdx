Semilattice is a user simulation API that predicts how specific user profiles would answer questions. Our API lets you simulate responses from any user profile, from software developers to marketing executives to general consumers.

## How it works

1. **Choose a population** - Select from public populations or create custom ones from your user data
2. **Ask questions** - Submit single-choice, multiple-choice, or open-ended questions  
3. **Get predictions** - Receive percentage distributions showing how the population would respond
4. **Validate accuracy** - Test populations against known data to understand reliability
