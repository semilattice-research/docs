Semilattice is a computational research platform that predicts how specific populations would answer questions. Our API lets you simulate responses from any demographic group, from software developers to marketing executives to general consumers.

## How it works

1. **Choose a population** - Select from public populations or create custom ones from your survey data
2. **Ask questions** - Submit single-choice, multiple-choice, or open-ended questions  
3. **Get predictions** - Receive percentage distributions showing how the population would respond
4. **Validate accuracy** - Test populations against known data to understand reliability

## API Overview

Our RESTful API provides endpoints for:

- **Population management**: Create, list, and test population models
- **Answer simulation**: Predict responses to new questions  
- **Benchmarking**: Validate population accuracy against known data
- **Result polling**: Monitor async prediction jobs

All endpoints support both single requests and batch operations for efficiency.
